# Multiply by 2

Implement a program that multiplies every element of a 1D array by 2.

The input consists of one array:

- `x`: A 1D array.

The output should be written to the `output` array, which has the same length as `x`.

The operation is defined mathematically as:

$$
output[i] = 2 \cdot x[i]
$$

where $i$ ranges from $0$ to $n-1$.

## Implementation Requirements

- Use only native features (external libraries are not permitted)
- The `solve` function signature must remain unchanged
- The final result must be stored in the array `output`

## Example 1

```text
Input: x = [1, 2, 3, 4]
Output: [2, 4, 6, 8]
```

## Example 2

```text
Input: x = [-3.0, 0.0, 1.5]
Output: [-6.0, 0.0, 3.0]
```

## Constraints

- $1 \leq n$
