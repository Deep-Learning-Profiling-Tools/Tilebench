# 01 — Aggregation contract (as implemented at `c4587b2c`)

Notation: `T` = per-case latency (ms), `S` = per-case speedup, `R` = per-case roofline utilization, `gm(·)` = equally-weighted geometric mean `exp(mean(log x))` (`scripts/analysis/bench_data.py::geomean`, numpy). All aggregation levels above the per-case latency are geometric means. No paper-level aggregate is an arithmetic mean or a macro-average.

### Zero / missing policy actually used by the final figure
* Zero-valued correctness-gated speedup (operator with no verify-clean iteration): BestSpeedup@10 = 0, TokenEfficiency@10 = 0 → **excluded** from the efficiency geomean (filter `> 0`); still **included** in the TokenCost geomean (its tokens are real). No epsilon. Ops concerned: GPT-5.5/cuTile {batched_matmul, streamk_matmul}; Claude/cuTile {batched_matmul, block_sparse_attention, streamk_matmul, top_k_selection}; none for either Triton run.
* Compilation failure / verification failure / per-case timeout at an iteration: all collapse to `verify_clean=False` for that (backend, iteration): speedup not recorded, tokens counted. The archived CSV does **not** distinguish compile-fail from verify-fail from timeout (`MISSING` at that granularity; only the raw run_summary.json/feedback.json had it).
* Missing iterations: an (op, model) run that froze both backends stops recording; those absent iterations contribute no tokens and no speedup (they are simply not in the sum/max). Skipped iterations of one backend while the other continued contribute nothing to the skipped backend.
* Unsupported dtypes: the LLM harness evaluated only the dtypes in the operator's `config.yaml`; a dtype missing from the trimmed grid is not part of any max/sum. NaN latency: treated as failure (verify not clean).
* Operators with no verify-clean iteration: counted in `n_ops_no_verify_clean_iter` (see `02_rq_summary.json`), BestSpeedup = 0, excluded from efficiency geomean, included in cost geomean.

`10_rq4_trajectory_summary.csv` follows the same positive-only rule per iteration and states it in its column names.
